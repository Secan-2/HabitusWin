HabitusWin 安装说明
====================

一、安装
  推荐双击「安装.command」。它会自动把应用复制到「应用程序」、注册到系统索引、
  刷新启动台缓存并启动应用，不需要手动拖拽。

  也可以手动把 HabitusWin 拖到左侧的「应用程序」文件夹，但装完要自己去访达里
  打开一次，启动台才会正确显示图标。

  务必从「应用程序」里运行。从 DMG、下载目录或 U 盘里直接运行，
  系统会把授权记在那个临时路径上，下次换位置就失效。

二、第一次打开被系统拦住怎么办
  HabitusWin 没有购买 Apple 开发者证书，系统不认识它的签名，
  所以第一次双击会提示「无法打开，因为无法验证开发者」。

  步骤（只需要做一次，系统会记住）：
  1. 先双击一次，看到拦截提示，点「完成」。
  2. 打开「系统设置 → 隐私与安全性」。
  3. 向下滚动，在「安全性」区域会看到一行
     「已阻止使用 HabitusWin，因为来自身份不明的开发者」。
  4. 点旁边的「仍要打开」，输入开机密码或用触控 ID 确认。
  5. 再双击一次应用，弹窗里点「打开」。

  做完这一次之后，以后启动和应用更新都不会再拦。

三、授权（顺序很重要）
  1. 打开 HabitusWin，菜单栏出现三个圆点图标。
  2. 左键点图标，进入设置，先到「红绿灯」或「剪切」页面把开关打开。
  3. 这时系统才会弹出授权请求，点「打开系统设置」。
  4. 在「隐私与安全性 → 辅助功能」列表里勾选 HabitusWin。
  5. 回到应用，1 到 2 秒内它会自动生效，不需要重启。

  为什么不能先去系统设置里找：
  应用没有主动请求过权限之前，不会出现在辅助功能列表里。
  如果列表里确实没有，也可以在设置页点「请求授权」。

四、授予后仍然显示未授予
  设置页「通用」这一页可以看诊断：
  - 运行位置：应该在 /Applications 下。
  - AX 接口自检：未授权时显示「AX 接口被系统禁用」。
  - 签名：本版本为 ad-hoc 自签名。

  处理顺序：
  1. 确认运行位置是 /Applications。
  2. 点「清理旧授权记录」，确认后系统会重新弹授权请求。
     （历史版本被替换后，系统里可能残留旧记录，导致勾选立刻跳回。）
  3. 重新勾选，然后回到应用看诊断是否变成「已授予」。
  4. 仍然不行就点「复制诊断信息」，把内容发给开发者。

五、三个功能怎么开
  1. 窗口红绿灯
     打开「接管窗口红绿灯」。默认动作是 红 = 关闭窗口，黄 = 最小化窗口，绿 = 切换全屏，
     也就是完全等同系统原生行为，只有你主动改动的那一项才会不同。

     红色按钮设成「退出应用」时，下面两类应用不接管，点击原样交给系统：
       一、访达这类系统常驻进程，退出会关掉全部窗口再被系统重新拉起。
       二、没有 Dock 图标的常驻应用（菜单栏工具），退出等于移除菜单栏图标。
     所以对访达点红色按钮，效果与系统原生完全一致。

     多窗口应用：只要该应用还开着其它窗口，点红色只关闭当前窗口，
     不会把全部窗口一起带走。最后一个窗口才触发退出。

     退出不彻底的处理：发出退出请求后，窗口已经清空的 0.6 秒收尾，
     还留着窗口的给满 1.2 秒。这是为了不让 Dock 图标底部一直留着运行指示。
     停在保存确认上的应用会被识别出来，不会被打断。

     首次使用「退出应用」时，系统会询问是否允许 HabitusWin 控制其它应用，
     点允许才能正常发出退出请求。

     实现方式是不绘制任何覆盖层，只在你点中按钮时拦下这一次点击并执行映射动作。
     所以拖动窗口不会有残影，鼠标悬停时按钮上的叉、横线、三角照常显示。
     代价是被拦下的那一次点击没有按下态的凹陷动画。

  2. Finder 剪切
     打开「启用 ⌘X 剪切」。选中文件按 ⌘X 会立刻响一声，到目标文件夹按 ⌘V 完成移动。
     音效在按下的瞬间播放，不依赖后面的复制是否成功。

     默认音效是随包的切纸声（Snip），下拉里还能选十余种系统音效。
     如果听不到声音，先在设置页点「试听」。
     试听也没声音说明是系统输出设备的问题，去「系统设置 → 声音 → 输出」确认没有选到
     BlackHole 之类的虚拟声卡。

  3. Dock 再次点击
     打开「启用」。同一颗 Dock 图标点第一下收起，点第二下展开，来回切换。
     访达同样适用：有窗口时点一下收起，再点一下展开。
     窗口已经全部最小化或应用已隐藏时，再点会主动还原并激活。

  4. 开机自动启动
     「通用」页顶部有开关。开启后登录系统会自动运行，只驻留菜单栏。
     应用需要放在「应用程序」文件夹里，否则系统会拒绝注册。

  4. 开机自动启动
     「通用」页顶部有开关。开启后登录系统会自动运行，只驻留菜单栏。
     应用需要放在「应用程序」文件夹里，否则系统会拒绝注册。

六、常见问题
  - 红绿灯没反应：只对当前前台应用的窗口生效。先在窗口上点一下让它成为前台，再试。
  - 后台窗口的红绿灯保持系统原生行为，这是有意为之。
  - 全屏窗口不做接管。
  - 覆盖层方案已废弃。旧版拖动窗口出现的残影来自独立透明面板跟不上系统窗口，
    这一版不再有两个窗口不同步的问题。
  - 诊断里「输入监听」显示未启动、原因是「事件监听创建失败」时，
    到「隐私与安全性 → 输入监控」里也勾选 HabitusWin，然后重启应用。
  - 重新编译或替换应用后授权可能失效（ad-hoc 签名按 CDHash 记忆授权），
    用「清理旧授权记录」重来一次。

七、卸载
  退出应用，把 /Applications/HabitusWin.app 拖到废纸篓。
  再到「隐私与安全性 → 辅助功能」里移除残留条目。
